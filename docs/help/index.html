TTSTT Help

TTSTT reads selected users' text messages aloud in your Discord voice channel, with per-user synthetic voices—so text-first members can be heard in voice.

Quick start

Run slash commands in a server text channel. The channel where you run /join becomes the control channel for that server.

  1. Join a voice channel, then run /join in the text channel you want to use.
  2. Run /tts_listen_user and pick whose messages should be read aloud.
  3. Those users post in the same text channel; the bot speaks their messages in voice.
  4. Optional: /tts_voice_set to customize your synthetic voice per server (use style none to clear style).
  5. Run /tts_stop_listening when you no longer want your messages read aloud.
  6. Run /leave when the bot should disconnect from voice.

In Discord, type /help anytime for a link back to this page.

Commands

Voice

Command What it does
/join Join your current voice channel and bind this text channel as the control channel.
/leave Disconnect from voice and clear TTS listeners for this server.
/status Show voice connection, control channel, and how many TTS listeners are active.
/help Open this help guide (link sent in Discord).

Text-to-speech (TTS)

Command What it does
/tts_listen_user Start reading a user's messages from the control channel aloud in voice.
/tts_stop_listening Stop reading your messages from the control channel aloud in voice.

Voice preferences (per user, per server)

Command What it does
/tts_voice_set Set Deepgram voice/model, speed (0.5–2.0), pitch (−20–20), and optional style (use none to clear style). Omit fields you do not want to change.
/tts_voice_show Show your saved TTS settings for this server.
/tts_voice_reset Reset your TTS settings to defaults for this server.

Privacy & safety

Before you use TTSTT: Text from listened users may be sent to speech AI services for synthesis. Only add the bot where members understand and consent.
  • /join warns that text from users you add with /tts_listen_user may be read aloud in voice after content safety checks.
  • TTS: Listened messages with sensitive content or links are not synthesized or played in voice.
  • Server operators can set OPENAI_API_KEY on the bot host for additional hate, harassment, and violence screening via OpenAI's Moderation API.

FAQ & troubleshooting

The bot does not respond to slash commands
Confirm the bot is online, invited with slash-command scope, and that command sync has finished after a deploy (global sync can take up to about an hour). Restart the bot after code updates.
/join fails
Join a voice channel first. The bot needs Connect, Speak, and View Channel in that voice channel. In the Discord Developer Portal, enable Guilds, Voice States, and Message Content privileged intents for the application.
TTS does not read my messages
Run /join in the text channel you want to use, then /tts_listen_user for your account. Messages must be posted in that same control channel while the bot is connected to voice.
Voice sounds broken or the bot crashes in voice
The host running the bot needs FFmpeg and Opus support. Set FFMPEG_EXECUTABLE if ffmpeg is not on PATH.
Voice preferences do not save
The bot requires a working DATABASE_URL (PostgreSQL). Run schema init once: python -m apps.bot.init_db.
